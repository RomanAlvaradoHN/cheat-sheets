# LINUX USERS AND GROUPS MANAGEMENT  

## CREATE USER  

```bash
#create user only
sudo useradd [username]
```  

```bash
#create user and home directory
sudo useradd -m [username]
```  

## DELETE USER  

```bash
#delete user only
sudo userdel [username]
```  

```bash
#delete user and home directory
sudo userdel -r [username]
```
